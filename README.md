# FDE 转型学习计划 · 工作目录

**起点**：中软国际 · Java 3年 + 前端 2年 + 管理 6年

**目标**：跳槽国内 AI 公司 FDE（前向部署工程师）

**周期**：2026-09-14 ~ 2027-01-03（112 天 / 336 项任务）

**节奏**：工作日 2h（周一至周五） + 周末 3h/天（周六、周日） = 16h/周，总计约 256h

## 怎么用这个目录

1. **每天早上**：打开 `weeks/` 下今天对应的 `Dxxx-xxxx.md`，照着做，逐条打勾 `- [ ]` → `- [x]`
2. **每天结束**：把任务卡底部的「复盘」三行写完，然后 `git add . && git commit -m "..."`
3. **每周日晚**：打开当周 `README.md`，核对过关门槛。达不到就重做本周，不要带着欠账往下走
4. 所有随手笔记丢进 `notes/`

> 你最大的风险不是学得慢，是「以为自己会了」。门槛不过，不许前进。

## 六个关键判断

1. **别藏那 6 年管理经验，那是你的主武器** —— FDE 的一半工作不是写代码，是界定问题、管住范围、推动客户组织改变。年轻工程师缺的正是这个。简历上要写「主导过 N 个大客户交付」，而不是「脱离技术 6 年」。

2. **Java + 大客户交付背景是你的护城河** —— 国内 AI 公司的 FDE 最头疼的就是对接客户那些十五年前的遗留系统。你懂 Java、懂国企和大客户的流程、懂什么叫等保合规，这是纯 AI 背景的人补不上的。W8 专门为这件事做了项目。

3. **Eval 优先于一切花哨技术** —— 2026 年 FDE 面试中，评测设计是权重最高的一环，很多候选人挂在「说不清自己的系统到底多好」。W6 整周都给它，性价比最高。

4. **英语只补到「能读 + 能写」就够** —— 国内 AI 公司不要求口语。你的目标是能直接读英文一手文档（中文二手资料普遍滞后 3-6 个月）、能写英文 README 和 commit。每天 20 分钟，16 周足够。

5. **国庆假期是黄金窗口** —— 10 月 1-7 日（W3 后半 + W4 前半）建议加码到 4-6 小时/天，正好用来收尾阶段一、提前启动 RAG。这段时间集中突破，能把整体进度提前 1-2 周。

6. **每周围槛不过就不要往下走** —— 你最大的风险不是学得慢，是「以为自己会了」。每个阶段末尾都有硬性门槛，达不到就重做那一周，别把欠账带到下一阶段。
