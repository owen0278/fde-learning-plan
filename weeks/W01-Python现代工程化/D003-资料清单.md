## 四、优先级判断

任务卡要求对比 asyncio / 线程池 / 进程池。判断规则记住这两条就够：

| 场景 | 用什么 |
| --- | --- |
| **等网络 / 等 IO**（调 LLM API、抓网页、查数据库） | `asyncio` |
| **CPU 密集**（图像处理、大批量计算、解析 PDF） | `ProcessPoolExecutor` |
| 只是不想改写成 async 的老代码 | `ThreadPoolExecutor` |

**为什么 asyncio 对你特别重要**：FDE 日常最典型的场景就是
「同时调 100 次大模型 API」或「批量处理客户的一万条数据」——
这类活全是 IO 等待，asyncio 能把耗时从 10 分钟压到 30 秒。
这是 AI 工程里性价比最高的一项技能。

⚠️ **别陷入 GIL 的兔子洞**。GIL 的原理看个大概就行，
今天的目标是能写出能跑的并发脚本，不是搞懂解释器内部实现。

建议做成三版对比，把数据记下来（这本身就是很好的作品集素材）：


## 七、今日英语（20 min）

从今天的文档里摘：

`coroutine` `await` `concurrent` `parallel` `synchronous` `asynchronous`
`event loop` `schedule` `timeout` `semaphore` `gather` `blocking` `throughput` `latency`

> 注意区分两个常被混用的词：`concurrency`（并发，交替执行）vs `parallelism`（并行，同时执行）。
