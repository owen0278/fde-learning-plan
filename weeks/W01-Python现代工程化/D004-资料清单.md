## 二、重点概念

### 依赖注入（今天最该搞懂的）

<https://fastapi.tiangolo.com/tutorial/dependencies/>

**为什么重要**：后面你会用它来注入数据库连接、当前登录用户、
LLM 客户端实例、配置对象。不理解依赖注入，
W07 之后写 Agent 服务时会写成一团乱麻。

至少要理解：`Depends()` 怎么工作、为什么它比在路由函数里直接 `new` 一个对象好
（答案：可测试、可替换、可复用）。

### 自动生成的 OpenAPI 文档

启动服务后访问这两个地址（任务卡要求手动调一遍）：

- `http://127.0.0.1:8000/docs` —— Swagger UI
- `http://127.0.0.1:8000/redoc` —— ReDoc

**这是 FastAPI 相对 Flask/Django 的决定性优势**：
你写了类型注解和 Pydantic 模型，接口文档自动生成，
前端和对接方拿去就能用 —— FDE 做客户交付时，
光这一项就能省掉大量写接口文档的时间。

## 三、今天的产出：内存版 CRUD API（交付项目台账）

任务卡的例子选得很好 —— **这是你的主场**。
你管了 6 年交付项目，台账该有哪些字段你比任何教程都清楚。

建议字段设计（最少要有这些，才会用到不同的校验类型）：

| 字段 | 类型 | 校验点 |
| --- | --- | --- |
| `project_name` | str | 非空、长度 1–100 |
| `client` | str | 非空 |
| `amount` | float | 大于 0 |
| `status` | enum | 只能是 进行中/已验收/已回款/风险 之一 |
| `due_date` | date | 不能早于今天 |
| `owner` | str | 非空 |

用 enum 和 `gt=0` 这类约束，才能真正练到 Pydantic 的校验能力 ——
只写 `str` / `int` 字段等于没练。

**加分项**：台账类 API 天然需要分页和筛选，
顺手加个 `skip` / `limit` 参数，这是真实项目必备的。
